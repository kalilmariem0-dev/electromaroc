# ElectroMaroc

Maquette d'un site de vente de produits électroniques en React.

## Technologies
- React
- JavaScript
- CSS

## Installation

1. Cloner le projet :
```bash
   git clone https://github.com/kalilmariem0-dev/electromaroc.git
```
2. Entrer dans le dossier :
```bash
   cd electromaroc
```
3. Installer les dépendances :
```bash
   npm install
```
4. Lancer le projet :
```bash
   npm start
```
